            How the agent’s purchase is checked
            

              A supplier-signed pass is bound to the original order. Payment
              releases only after the independent checker confirms the purchase
              and delivery. The QR is then redeemable once in OY’s persistent
              server ledger.
            

            

            

            

              The demo uses a funded operator wallet and separate supplier
              funds: 0.01 tSOL on Solana Devnet and 2 tADA on Cardano preprod.
              There is no currency swap or bridge. Verification uses an official
              Chainlink CRE simulation and a trusted settlement relayer. Pass
              redemption is recorded on the server, not on chain.

                THE WORKER’S REWARD
                
    Held until the work checks out.
    
                
    
                  The reward is paid after the checks pass. If they fail, it

                THE REPORT’S PRICE
                
    Spent when the report is bought.
    
                
    
                  The worker pays a data seller to get the report. That purchase
                  is separate and stays spent even if the report’s answer is
                  wrong.
                
    
              
    
            
    
            
    
              
    What does this demo actually check?
    
              
    
                Numbers in a crypto-wallet report: transaction fees and when
                transactions were recorded. It also checks the report’s purchase
                and the task’s payment rules.
              
    
              
    Why is that useful?
    
              
    
                A confident answer or a signed report can still be wrong.
                Checking the original records before paying gives the buyer a
                way to catch mistakes.
              
    
              
    Does this use real money?
    
              
    
                The transaction records are real. Payments in this demo use test
                coins with no cash value. The Demo tab replays completed tasks;
                Try a fake answer runs a fresh check.
              
    
              
    Is an AI writing this report?
    
              
    
                This prototype uses an automated reporting worker. It
                demonstrates the payment and checking rules that an AI worker
                can use.
              
    
            
    
            
    
              Technical details and sponsor connections
              
    
              
    
                
    The trust boundary
    
                
    
                  The baseline uses a local CRE simulation and a trusted
                  settlement relayer. It does not claim decentralized production
                  execution. The server’s Cardano signer enforces purchasing
                  limits; the Solana program enforces task escrow. The operator
                  pays the supplier and bears that cost if verification fails.
